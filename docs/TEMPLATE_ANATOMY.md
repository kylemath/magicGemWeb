Each Magic Gem template consists of several types of elements. Here's what everything means:

## Element Types

### 1. Triangular Faces
```
      • Vertex (cell value)
     ╱│╲
    ╱ │ ╲
   ╱  │  ╲
  •───┼───•
      │
   Center (face label)
```

**What it is**: Each triangle represents one face of the 3D magic gem
**What to do**: These form the surface of your final model
**Colors**: Faces with the same color have identical geometry

### 2. Cut Lines
```
  ──────────── (solid black, 2-3px thick)
```

**What it is**: Edges you should cut with scissors
**What to do**: Cut along these lines completely
**Tip**: Use sharp scissors for clean edges

### 3. Fold Lines  
```
  ╎╎╎╎╎╎╎╎╎╎╎╎ (dashed gray, 1-2px)
```

**What it is**: Edges shared between two faces
**What to do**: Fold along these lines (don't cut!)
**Tip**: Score first with ruler + empty pen for crisp folds

### 4. Glue Tabs
```
     ┌───────┐
     │ GLUE  │ (light gray trapezoid)
     └───────┘
```

**What it is**: Extra material for gluing faces together
**What to do**: Apply glue here, press against matching edge
**Tip**: Use less glue than you think - too much makes it messy

### 5. Face Labels
```
    "F1", "F2", "F3", ... (white text on black outline)
```

**What it is**: Identifier for each face
**What to do**: Use for reference during assembly
**Tip**: Optional - can toggle off if you prefer clean faces

### 6. Cell Values
```
    7, 9, 8 (black text at triangle vertices)
```

**What it is**: Original magic square values
**What to do**: Educational reference - shows 3D structure
**Tip**: Optional - can toggle off for cleaner appearance

### 7. Instructions Box
```
  ┌─────────────────────────────────┐
  │ 📋 PAPER CRAFT INSTRUCTIONS     │
  │ 1. Print on card stock          │
  │ 2. Cut along solid lines        │
  │ 3. Fold along dashed lines      │
  │ 4. Apply glue to gray tabs      │
  │ 5. Press tabs against edges     │
  └─────────────────────────────────┘
```

**What it is**: Quick reference guide
**What to do**: Follow these steps!
**Tip**: Can toggle off before printing for more space

## Color Guide

### Face Group Colors

The template uses distinct colors to group faces by geometry:

```
🟦 DARK BLUE    - Largest triangles (typically 4-8 faces)
🟥 RED          - Medium triangles (typically 2-6 faces)  
🟩 GREEN        - Smaller triangles (typically 2-4 faces)
🟨 YELLOW       - Smallest triangles (typically 2 faces)
🟪 PURPLE       - Special geometry faces
🟧 ORANGE       - Additional unique shapes
... (up to 16 different groups)
```

**Why colors matter**:
- Same color = same shape = interchangeable
- Helps verify symmetries
- Makes assembly easier to follow
- Beautiful final result!

## Measurement Reference

### Typical Template Dimensions

For a standard 4×4 magic square template:

```
Overall Size:     ~8" × 8" (on letter paper)
Face Size:        ~0.5" - 1.5" per edge
Tab Width:        ~0.2" - 0.3"
Line Thickness:   
  - Cut lines:    2-3 pixels
  - Fold lines:   1-2 pixels
Margins:          ~0.5" all around
```

### Scaling Guide

Want a bigger or smaller model?

| Print Scale | Final Model | Use Case |
|------------|-------------|----------|
| 50%        | Tiny (1")   | Collection, keychain |
| 100%       | Small (2")  | Desktop display |
| 200%       | Medium (4") | Classroom demo |
| 300%       | Large (6")  | Museum display |

## Assembly Symbols

When assembling, look for these patterns:

### Connected Faces (Fold)
```
  Face A ╎╎╎╎╎╎╎ Face B
  (fold between them)
```

### Separate Faces (Glue)
```
  Face A ────[tab]
  
  Face B ────────
  (glue tab to edge)
```

### Valley Fold (fold toward you)
```
      ╱│╲
     ╱ ↓ ╲
    ╱  │  ╲
```

### Mountain Fold (fold away)
```
    ╲  │  ╱
     ╲ ↑ ╱
      ╲│╱
```

## Tips for Reading Your Template

### Before You Start
1. **Print test**: Print at 50% first to test
2. **Identify folds**: Mark all dashed lines  
3. **Count faces**: How many triangles?
4. **Plan route**: Which order to glue?

### During Assembly
1. **Check orientation**: Face labels help
2. **Dry fit**: Test before gluing
3. **One tab at a time**: Don't rush
4. **Hold firmly**: Wait for glue to set

### Quality Check
- All folds crisp and aligned? ✓
- No gaps between faces? ✓
- Tabs hidden inside? ✓
- Shape matches 3D preview? ✓

## Common Template Patterns

### Pattern 1: Star Layout (Symmetric)
```
        [F1]
         │
    [F2]-│-[F3]
         │
        [F4]
```
Center face with radiating connections

### Pattern 2: Strip Layout (Sequential)
```
[F1]─[F2]─[F3]─[F4]─[F5]
```
Linear sequence, easy to follow

### Pattern 3: Clustered (Spanning Tree)
```
    [F1]─[F2]
     │    │
    [F3]─[F4]
     │
    [F5]
```
Tree structure, minimal cuts

## Troubleshooting Visual Guide

### Problem: Tab doesn't reach edge
```
   ┌──────┐
   │      │
   [tab]  │  ← Gap!
          │
```
**Solution**: Slight overlap OK, or extend with tape

### Problem: Faces don't line up
```
   ╱╲
  ╱  ╲_____ ← Edge mismatch
  ╲    ╱
   ╲__╱
```
**Solution**: Re-fold more accurately, or trim slightly

### Problem: Tab too wide
```
   ┌──────────────┐
   [  WIDE TAB  ]  ← Overlaps other faces
```
**Solution**: Trim tab narrower before gluing

## Success Indicators

Your template is working if:

✅ Tabs fit against edges naturally  
✅ Shape is becoming 3D
✅ Colors make geometric sense
✅ Final form is rigid and stable
