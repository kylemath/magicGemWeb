Magic Square as Orbital System

Each particle represents a cell from Dürer's magic square.

Distance from center = Cell value

Value 1 orbits closest (1 unit), value 16 orbits farthest (16 units). All particles have equal mass, spinning on random orbital planes.

Like electrons in shells, but the "shell number" is the value itself.
